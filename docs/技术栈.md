# Rhythm 后端技术栈清单

| 类别 / 领域 | 选定技术栈 | 职责与说明 |
| :--- | :--- | :--- |
| **基础框架** | **NestJS** | 企业级 Node.js 模块化架构与依赖注入（DI） |
| **底层引擎** | **Express** (`@nestjs/platform-express`) | 成熟稳定的 HTTP 服务底座 |
| **开发语言** | **TypeScript** | 静态强类型支持（严格模式） |
| **包管理器 / 架构** | **pnpm (Monorepo)** | 多端统一包管理与代码共享 |
| **数据库** | **PostgreSQL 17** | 本地 Docker 部署，时区 (TIMESTAMPTZ) 与 JSON 特性支持 |
| **ORM / 数据层** | **Prisma** | Schema 驱动建模、类型安全的数据库客户端与数据迁移 |
| **请求上下文** | **nestjs-cls** | 基于 Node 原生 `AsyncLocalStorage`，全链路隐式透传上下文，零参数污染 |
| **身份认证** | **@nestjs/jwt** | 原生守卫 (AuthGuard) 自签自验，抛弃 Passport 冗余抽象 |
| **令牌策略** | **双 Token 轮转机制** | Access Token (15m 短期) + Refresh Token (7d 长期)，支持无感刷新与主动注销 |
| **密码哈希** | **bcryptjs** | 慢哈希加盐加密，防暴力破解与时序攻击 |
| **参数校验与 DTO** | **Zod + nestjs-zod** | 单一真实数据源，前后端统一 Schema 校验，自动推导类型与 DTO |
| **API 接口文档** | **@nestjs/swagger** | OpenAPI 规范，由 Zod DTO 自动推导生成交互式文档 |
| **日期与时区** | **Day.js** | 轻量级时间库，负责 UTC 时间与用户本地时区转换 |
| **环境变量管理** | **@nestjs/config + Zod** | 应用启动时强校验 `.env` 关键配置有效性 |
