# Rhythm 移动端功能设计备忘录（所向 · 时序 · 复盘）

> 本文档用于固化在移动端原型讨论中已确认的设计方案，严格对照 Web 端（`apps/web`）完整业务能力，杜绝功能断层，以便后续研发与交互还原。
> 注：**习惯模块 (Habits)** 已于前期完成并单独固化，本文档聚焦于其余三大核心模块：**所向 (Direction)**、**时序 (Day)**、**复盘 (Summary)**。

---

## 1. 所向模块 (Direction) 设计备忘

### 1.1 核心定位与三级级联体系
所向模块是 Rhythm 的长期战略引擎，承载 **“目标 (Plans) → 月度战役 (Monthly Plans) → 批量排期日任务 (Daily Tasks)”** 的三级级联结构：
1. **目标 (Goal)**：定义宏观方向（如“掌握 Rust 异步系统编程”、“半程马拉松 21km”），指定起止月份、所属分类及默认执行时间；
2. **月度战役 (Monthly Plan)**：将目标拆解到目标月份内的每一个月（如 5月：所有权与并发基石；6月：Tokio 与网络编程）；
3. **批量排期日任务 (Daily Tasks)**：在月份日历上多选日期（支持按星期一键连选），批量生成日任务，**自动下发并同步至「时序 (Day)」当天的任务时间轴中**。

---

### 1.2 新增 / 编辑目标大卡片 (GoalModal · 完整对齐 Web 端)
呼出方式：主界面底部悬浮加号（FAB）在所向页点击时呼出，或点击目标卡片上的“设置/编辑”呼出。

采用 iOS 标准贴底大卡片 (`rounded-t-[32px]`)，包含以下 6 项核心业务字段：
1. **目标名称**：必填输入框，支持回车快速保存；
2. **执行起止月份 (Start ~ End Month)**：
   - 双列选择器：开始月份（1~12月）与 结束月份（1~12月）；
   - 联动校验：结束月份不得早于开始月份；
3. **目标分类与分类管理**：
   - 分类单选标签 Pills（如 `学习`、`健康`、`工作`、`生活`、`未分类`）；
   - 内联提供「管理分类」快捷入口（轻触展开分类增删管理）；
4. **默认时间与预计时长**：
   - 默认执行时间（如 `09:00`）；
   - 预计时长（如 `45 分钟`）；
   - **编辑模式特有开关**：`同步更新子级时间`（勾选后一键覆盖已创建的月度战役时间）；
5. **未完成延后展示 (Carry-Over 机制)**：
   - 分段开关：`[关闭] / [开启]`；
   - 开启后输入顺延天数（如 `3 天`），过期未完成的目标任务会在时序轴上向后顺延展示；
6. **操作与危险操作**：
   - 编辑模式左侧提供标红「删除此目标」按钮（需二次确认）；
   - 右侧「取消」与「确认创建 / 确认修改」主按钮。

---

### 1.3 月度任务视板与批量排期 (MissionBoard · 移动端适配)
轻触任意目标卡片进入「目标详情 / 战役视板」：
1. **目标执行时轴 (GoalRangePicker)**：
   - 顶部显示目标名称与分类胶囊；
   - 12 月份横向执行轴，高亮目标起止区间（如 05月 ~ 08月），支持微调；
2. **月份折叠战役卡片 (MissionBoardMonth)**：
   - 展开某个月份（如 `05月`）：
     - 输入当月作战核心标题（如 `Tokio 核心机制突破`）；
     - 显示/修改当月默认任务时间与时长；
3. **月份日历网格与批量选天**：
   - 星期表头（周一到周日）：**轻触“周一”可一键全选当月所有周一**（极其适合每周定频训练）；
   - 7 列日期网格：轻触单日或多日连选，高亮选中天数；已有排期的日期下方带有圆点标识；
4. **底部浮动批量排期栏 (Batch Action Bar)**：
   - 当有 N 天被选中时，底部浮起输入框：
     - `已选 N 天` 徽标；
     - 任务内容输入框（如 `刷 2 题 LeetCode + 读源码`）；
     - 操作按钮：未排期日期显示 `[应用批量排期]`；全选已有任务日期时显示 `[修改]` / `[批量删除]`；
   - **核心联动**：应用后，系统自动在「时序」页对应的 N 个日期的日程列表中追加该日任务！

## 2. 时序模块 (Day) 设计备忘

### 2.1 核心定位与多源数据汇聚
时序页面是用户每天高频交互的“作战中枢”。它不只是普通待办列表，而是汇聚全系统行动的统一流水线：
- **普通待办 (Task)**：用户当天随手创建的临时事项；
- **所向日任务 (GoalDay)**：来自「所向」模块批量分配的战役任务（标有所属目标标签与预计时长）；
- **日常习惯 (Habit)**：设定了具体时间的打卡项（如早起晨读），准时出现在时序流中。

---

### 2.2 新增 / 编辑事项大卡片 (TaskModal · 对齐 Web 端)
呼出方式：时序主界面点击悬浮加号（FAB），或点击已有事项进行编辑。

包含以下 5 项业务字段：
1. **事项名称 (Title)**：必填，支持回车直接提交；
2. **任务时间与预计时长 (Time & Duration)**：
   - 任务时间（如 `10:30`）；
   - 预计时长（如 `30` 分钟，步进 5 分钟），并排展示；
3. **任务描述 (Description)**：
   - 可选详细备忘输入框（如“带上打印材料，重点沟通第二阶段进度”）；
4. **事项分类标签组 (Category)**：
   - 单选分类胶囊（`工作`、`生活`、`健康`、`学习`、`未分类`）；
   - 支持内联分类管理；
5. **操作栏**：
   - 编辑模式提供「删除此事项」；
   - 主按钮「保存事项」。

## 3. 总结复盘模块 (Summary) 设计备忘

### 3.1 核心定位与成长闭环
拒绝无指导的空白随笔，打通系统真实数据，实现 **“数据自动聚合 + 经典深度反思三问”** 的成长闭环。

---

### 3.2 交互架构与数据自动聚合
1. **主页面（复盘流）**：
   - 顶部毛玻璃分段控制：`[日] [周] [月] [年]`；
   - 卡片上增加**数据徽标**：`待办完成 5/7 (71%)` · `打卡 2 个习惯`；
   - 预览折叠显示【今日成就】、【改进反思】、【明日焦点】摘要；
   - 点击某篇历史复盘，可展开查看或重新编辑。
2. **今日深度复盘大卡片 (SummaryModal · 点击 FAB 呼出)**：
   - **今日数据聚合卡**（系统自动读取今日待办和习惯生成，无需手写）：
     - 待办完成比与百分比（如 `5/7 · 71%`）；
     - 今日已打卡习惯数（如 `2/3`）；
     - 今日已完成项胶囊 Pills（如 `[晨读] [架构方案] [原型精修]`），给用户直观成就感；
   - **三段式结构化反思输入框**：
     - ① **今日成就**：今天完成了哪些重要事情？做成了什么？建立了什么信心？
     - ② **改进之处**：有哪些地方可以做得更好？哪里偏离了节奏？存在什么阻碍？
     - ③ **明日计划 / 焦点**：明天最优先处理、睁眼必须拿下的 1~3 件事是什么？
   - **周期复盘表单（周/月/年）**：
     - 支持周期评分（1~5星）、周期核心成果、下一阶段重点规划。

---
