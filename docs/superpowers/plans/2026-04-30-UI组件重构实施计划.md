# UI 组件重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 12 个 UI 组件的 Reusables 映射审计与改造，替换 login.tsx 和 day.tsx 页面组件，视觉风格与 rhythm web 保持一致。

**Architecture:** 分层重构 — 组件层 (src/components/ui/) 先完成 Reusables 映射和改造，验证 TypeScript 编译通过后，再推进页面层 (login.tsx, day.tsx) 重构。

**Tech Stack:** React Native Reusables, NativeWind, expo-router, TypeScript

---

## 文件结构

```
src/components/ui/           # UI 组件层 (12 个组件)
app/(auth)/login.tsx        # 登录页 (阶段二)
app/(app)/day.tsx           # 日视图路由
src/features/day/screens/DayScreen.tsx  # 日视图主件
global.css                  # 全局样式
```
